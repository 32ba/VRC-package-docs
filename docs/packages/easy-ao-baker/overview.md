EasyAOBaker は VRChat アバター向けの AO (陰影) 焼き付けツールです。アバターに 1 つコンポーネントを追加してアップロードするだけで、服のシワや首元・脇・指の間などに自然な陰影が入り、立体感のあるアバターに仕上げられます。

## このツールでできること

- **陰影を自動で追加**: 首元・脇・服のシワ・指の間など、光が届きにくい部分に自然な陰影が入ります。
- **アバターを壊さない**: 元のメッシュやマテリアルは一切変更されません。アップロード時にだけ陰影が適用されます。
- **ワンクリックで適用**: コンポーネントを 1 つ追加するだけ。細かい設定なしでも自然な仕上がりになります。
- **対応シェーダーが多い**: lilToon / Poiyomi / VRChat Toon Standard / Unity Standard など主要なアバター用シェーダーに対応しています。シェーダーは自動で判別されます。
- **日本語 UI**: English / 日本語 / 中文 / 한국어 に対応しています。
- **プレビューで事前確認**: アップロード前に Play モードで仕上がりを確認できます。

## こんな人におすすめ

- アバターをもっと立体的に見せたい
- 陰影を自分で描き込むのは面倒、でも仕上がりはきれいにしたい
- 他のメッシュと同じ要領で扱えるシンプルなツールを探している

## 必要なもの

- Unity 2022.3 LTS (VRChat Creator Companion が案内するバージョン)
- NDMF 1.9.0 以上 (VPM から一緒にインストールされます)

## ドキュメントの構成

- **前提条件**: 必要な環境とインストール方法
- **クイックスタート**: 最初の 1 回のベイクを試してみる
- **ガイド**: 仕上がりの微調整、部分的な除外、手動ベイクなど
- **トラブルシュート**: よくある質問と対処法
- **リファレンス**: Inspector の設定項目一覧

## 用語について

- Unity や VCC の UI は日本語表示を基準に書いています。
- EasyAOBaker の Inspector でも一部の項目名 (`Bake Mode`, `RayCast` など) は日本語 UI でも英語のまま表示されます。本書でも実際のラベルに合わせています。
