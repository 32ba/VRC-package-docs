メッシュを直接書き換えずに、Unity 上で形を整えたい。
Lattice Deformation Tool は、そのための VRChat 向けメッシュ変形エディタ拡張です。
ラティスケージとブラシの二種類のレイヤーを組み合わせ、変形結果を NDMF のビルド時に適用します。

## 主な特徴

- **非破壊ワークフロー**：NDMF（Non-Destructive Modular Framework）と連携し、元メッシュを書き換えずに変形をプレビューできます。
  変形はビルド時にベイクされます。
- **レイヤーとグループ**：ラティスレイヤーとブラシレイヤーを重ね、変形を段階的に管理できます。
  グループごとに独立した変形セットを構成できます。
- **ラティス編集**：単一の `Mesh Deformer` ツールとオーバーレイからケージの制御点を動かし、メッシュ全体を変形します。
  対称編集、制御点の表示範囲、補間方式を切り替えられます。
- **ブラシツール**：メッシュ表面をなぞり、法線方向の押し出し、移動、平滑化を行います。
- **頂点選択ツール**：ブラシレイヤーの頂点を選び、移動、回転、スケールで変形します。
  周囲を追従させるプロポーショナル編集も使えます。
- **BlendShape の入出力**：グループの変形結果を BlendShape（ShapeKey）として出力でき、既存の BlendShape はブラシレイヤーとして読み込めます。
- **左右操作**：片側の変形だけを残す操作と、各軸で変形を反転する操作を使えます。
- **ボーンウェイト再計算**：近傍転写と反復補間により、大きく変形したメッシュのボーンウェイトを再計算します。
- **5 言語の UI**：English、日本語、한국어、简体中文、繁體中文に対応しています。

## 1.4.2 の更新と移行

1.4.2 では Scene ビュー上の編集処理が最適化されました。
Undo と Redo の安定性が向上し、編集中の BlendShape のちらつきが抑えられています。
SkinnedMeshRenderer の現在のポーズに、ラティスケージが追従するようになりました。

更新後、旧 `BrushDeformer` は、ロード済みの Scene、Prefab Stage、`Assets` 内のインポート済み Prefab から検出されます。
Play Mode、コンパイル、インポート処理の最中には移行されません。
読み取り専用のアセットと Packages 内のアセットも変更されません。

変位と再構築設定は、`LatticeDeformer` の専用グループとブラシレイヤーへ移行されます。
旧コンポーネントは削除されず、無効なバックアップとして残ります。
検証または移行に失敗した場合は元データが保持され、Console に警告が出ます。

:::caution
自動移行により、Scene や Prefab が変更済みになることがあります。
パッケージを更新する前に、プロジェクトをバージョン管理へコミットするか、バックアップしてください。
:::

## 必要環境の要約

- Unity 2022.3 LTS 以降（VRChat Creator Companion 推奨バージョン）
- NDMF 1.9.0 以上

## ドキュメント構成

- **前提条件**：必要な環境と互換性
- **クイックスタート**：`Mesh Deformer` コンポーネントの基本設定から NDMF ビルドまでの手順
- **ガイド**：レイヤーとグループ、ブラシツール、頂点選択ツール、BlendShape、左右操作、ウェイト転送の詳細
- **トラブルシュート**：よくある症状と確認ポイント
- **リファレンス**：Inspector と Scene ツールの設定項目

## 用語と表記について

- Unity と VCC の UI は日本語表示を基準に記載し、必要に応じて英語表記を括弧内に併記します。
- Lattice Deformation Tool 本体の一部項目は日本語 UI でも英語のまま表示されます。
  本書でも実際のラベルに合わせた表記を使用します。
