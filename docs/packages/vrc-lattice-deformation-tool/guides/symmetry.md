## 左右操作（L/R Operations）

Inspector のレイヤー操作メニューにある `L/R Operations` は、選択中の一つのレイヤーへ左右処理を適用します。
操作は Undo と Redo に対応しています。

| 操作 | 対象 | 挙動 |
| --- | --- | --- |
| `Split L` | X 軸 | X の負側（左側）の変形だけを残し、正側を中立状態へ戻す |
| `Split R` | X 軸 | X の正側（右側）の変形だけを残し、負側を中立状態へ戻す |
| `Flip X`、`Flip Y`、`Flip Z` | 選択した軸 | レイヤー全体の変形を指定軸で反転する |

### レイヤーごとの挙動

- **ラティスレイヤー**：`Split L/R` はケージのグリッド中央を境界として、捨てる側の制御点を変形前の位置へ戻します。`Flip X/Y/Z` は反対側の制御点オフセットを入れ替え、指定軸方向の成分を反転します。
- **ブラシレイヤー**：`Split L/R` はソースメッシュ頂点のローカル X 座標で側を判定し、捨てる側の変位をゼロにします。`Flip X/Y/Z` は対応するミラー頂点どうしの変位を入れ替え、指定軸方向の変位成分を反転します。

ブラシレイヤーの反転では、許容範囲内に対称頂点が見つからない非対称頂点を、自分自身の対応先として扱います。
そのため、変位は別の頂点へ移らず、指定軸方向の成分だけが反転します。
中心面上の頂点も同様に自己対応です。
ラティスレイヤーは規則的なケージ座標どうしを対応させるため、メッシュ側に非対称な頂点があっても処理方法は変わりません。

片側だけで作った変形を反対側へ移したい場合は、対応する軸の反転を使います。
左右で別々の BlendShape を作る場合は、レイヤーを複製してから `Split L` と `Split R` をそれぞれ適用します。

## 編集中の対称操作

これから左右を同時に編集するなら、変形後に左右操作を適用する必要はありません。
各ツールの**対称編集**を有効にすると、編集中に対称軸の反対側へも変形が反映されます。

- **ラティス編集**: `Mesh Deformer` オーバーレイの <Icon name="mirror" /> `対称編集を有効化` → `対称モード` (`コピー` / `ミラー` / `反対称`) と `対称軸` を設定
- **ブラシ編集**: 同じオーバーレイの <Icon name="mirror" /> `ミラーを有効化` → `ミラー軸` を設定
