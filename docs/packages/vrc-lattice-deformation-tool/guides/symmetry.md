<Icon name="mirror" alt="ミラー" /> 左右で同じ変形を作る方法は、編集前と編集後で異なります。
編集中は対称編集を使い、完成した変形を片側へ分けたり反転したりするときは左右操作を使います。

## 左右操作（L/R Operations）

Inspector の `左右操作` は、現在のレイヤーに記録された変形を分割または反転します。

| 操作 | 結果 |
| --- | --- |
| `左を残す` | X 軸の片側にある変形だけを残し、反対側の変形をゼロにする |
| `右を残す` | `左を残す` とは反対側の変形だけを残す |
| `X反転` | X 軸を基準に変形データを反転する |
| `Y反転` | Y 軸を基準に変形データを反転する |
| `Z反転` | Z 軸を基準に変形データを反転する |

片側だけで作った変形を反対側へ移したい場合は、対応する軸の反転を使います。
左右で別々の BlendShape を作る場合は、レイヤーを複製してから `左を残す` と `右を残す` をそれぞれ適用します。

## 編集中の対称操作

これから左右を同時に編集するなら、変形後に左右操作を適用する必要はありません。
各ツールの**対称編集**を有効にすると、編集中に対称軸の反対側へも変形が反映されます。

- **ラティスツール**: オーバーレイの <Icon name="mirror" /> `対称編集を有効化` → `対称モード` (`ミラー` / `反対称`) と `対称軸` を設定
- **ブラシツール**: オーバーレイの <Icon name="mirror" /> `ミラーを有効化` → `ミラー軸` を設定
