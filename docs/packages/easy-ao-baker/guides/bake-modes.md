既定値でベイクした陰影が濃い、粗い、広がりすぎる。
その差は、`詳細設定` にある強度、計算範囲、サンプル数、ブラーで調整できます。

## ベイクモードの選び方

`ベイクモード (Bake Mode)` には 2 つのモードがあります。

| モード | 仕上がり | 時間 | おすすめの用途 |
| --- | --- | --- | --- |
| **RayCast** (デフォルト) | 正確でリアル | 普通 | 本番のアップロード |
| **SSAO** | 軽めの近似 | 速い | 何度も試してパラメータを探るとき |

最終出力では、指の間や服のシワまで拾える `RayCast` を使います。

SSAO は短時間で結果を確認できますが、複雑な形状では陰影にムラが出やすくなります。
SSAO でパラメータを決めた後、RayCast で本番用に焼き直すと待ち時間を抑えられます。

## 陰影の濃さを変えたい

### 全体の濃さ

`強度 (Intensity)` で陰影の濃さ全体を調整できます。

- 濃すぎる → `0.5` など小さい値に
- 薄すぎる → `1.5`〜`2.0` など大きい値に

### シェーダー別の濃さ

シェーダーごとに、さらに細かく濃さを調整できます。
たとえば lilToon では、1st Shadow、2nd Shadow、3rd Shadow への適用量を個別に変えられます。
各項目の働きは、[シェーダー連携](./shader-integration.md)を参照してください。

## 陰影の範囲を変えたい

### RayCast モードの場合

- **最大レイ距離 (Max Ray Distance)**: 陰影を拾う範囲 (メートル)。デフォルト `2.0`。
  - 短く (`0.5` 程度) → シワや隙間などの近い陰影だけ
  - 長く (`5.0` 程度) → 腕と胴体の間など、遠くの部分の陰影も入る

### SSAO モードの場合

- **半径 (Radius)**: 陰影を拾う範囲 (メートル)。デフォルト `0.15`。用途は上記と同じです。

## 陰影がざらつく、ノイズが乗る

ノイズが気になる場合は以下を試してください。

### RayCast モードの場合

- **レイ数 (Ray Count)** を増やす: デフォルト `128` → `256` など。滑らかになりますが時間はかかります。
- **ブラー反復回数 (Blur Iterations)** を増やす: デフォルト `1` → `2` や `3`。全体的にふんわりした仕上がりになります。

### SSAO モードの場合

- **サンプル数 (Sample Count)** を増やす: デフォルト `256` → `512` など。
- **カメラ方向数 (Camera Directions)** を増やす: デフォルト `128` → `256` など。

## 陰影がにじむ、広がりすぎる

- **ブラー反復回数 (Blur Iterations)** を減らす: `1` → `0` でブラーなしになります。
- **ブラー半径 (Blur Radius)** を小さく: デフォルト `0.5` → `0.25` など。

## ベイクに時間がかかる

- **解像度 (Resolution)** を一段下げる: `4096` → `2048`、`2048` → `1024` など。仕上がりを確認する段階では `1024` でも十分です。
- RayCast モードで時間がかかりすぎる場合は、SSAO モードで試してパラメータを固めてから、最後に RayCast に戻して本番ベイクするのがおすすめです。

## よくある組み合わせの目安

| 目的 | おすすめ設定 |
| --- | --- |
| 通常のアップロード (バランス重視) | RayCast / 解像度 2048 / レイ数 128 (デフォルト) |
| より高品質にしたい | RayCast / 解像度 4096 / レイ数 256 / ブラー反復 2 |
| とにかく速く試したい | SSAO / 解像度 1024 / サンプル数 128 |
| 全体的にふんわりさせたい | `ブラー反復回数` を `2`〜`3` に |
| くっきりした陰影が欲しい | `ブラー反復回数` を `0` に、`強度` を上げる |
