服のシワや首元、脇、指の間に陰影が入ると、アバターの立体感は大きく変わります。
EasyAOBaker は、その AO（陰影）をアバターへ自動で焼き付けるツールです。
対象のメッシュにコンポーネントを一つ追加すれば、アップロード時に陰影が適用されます。

## EasyAOBaker の特徴

- **陰影を自動で追加**：首元、脇、服のシワ、指の間など、光が届きにくい部分に自然な陰影が入ります。
- **非破壊で適用**：元のメッシュやマテリアルは変更されず、アップロード時にだけ陰影が適用されます。
- **少ない設定で開始**：コンポーネントを一つ追加すれば、既定値のままでもベイクできます。
- **主要シェーダーに対応**：lilToon、Poiyomi、VRChat Toon Standard、Unity Standard などを自動で判別します。
- **4 言語の UI**：English、日本語、简体中文、한국어 に対応しています。
- **アップロード前に確認**：Play モードで仕上がりをプレビューできます。

## 向いている用途

- アバターの立体感を補いたい
- 陰影を手描きせず、仕上がりを整えたい
- メッシュごとに手早く設定できるツールを使いたい

## 必要なもの

- Unity 2022.3 LTS（VRChat Creator Companion が案内するバージョン）
- NDMF 1.9.0 以上（VPM から一緒にインストールされます）

## ドキュメントの構成

- **前提条件**：必要な環境とインストール方法
- **クイックスタート**：最初の 1 回のベイクを試してみる
- **ガイド**：仕上がりの微調整、部分的な除外、手動ベイクなど
- **トラブルシュート**：よくある質問と対処法
- **リファレンス**：Inspector の設定項目一覧

## 用語について

- Unity や VCC の UI は日本語表示を基準に書いています。
- EasyAOBaker の Inspector でも一部の項目名（`Bake Mode`, `RayCast` など）は日本語 UI でも英語のまま表示されます。
  本書でも実際のラベルに合わせています。
