陰影を調整するたびにアバターをアップロードする必要はありません。
Inspector の `今すぐAOをベイク` ボタンを使えば、その場で仕上がりを確認したり、テクスチャだけを書き出したりできます。

## 手動ベイクの手順

1. `EasyAOBaker` Inspector の `詳細設定` を展開します。
2. 一番下にある `今すぐAOをベイク (Bake AO Now)` ボタンと、その上の `テクスチャのみ（手動ベイク） (Texture Only (manual))` を確認します。
3. ボタンを押すと即座にベイクが始まり、完了するとダイアログで出力先が表示されます。

<img src="/docs/img/packages/easy-ao-baker/easyaobaker-advanced-bake-button.webp" alt="詳細設定セクション。テクスチャのみトグルと今すぐAOをベイクボタンが見える状態" />

:::note
手動ベイクでも、処理対象のルート以下にある有効な Renderer を考慮して陰影を計算します。
親階層に `VRC Avatar Descriptor` があれば、その GameObject をルートとして使います。
見つからない場合は、EasyAOBaker からたどれる最上位の GameObject を使います。
:::

## `テクスチャのみ` の 2 つの動作

### ON（既定値）：PNG のみを書き出す

- 陰影のテクスチャ (PNG) が保存されるだけで、アバターのマテリアルは一切変更されません。
- 「ひとまず結果を見たい」「Photoshop などで確認してから使いたい」ときに便利です。

### OFF：マテリアルへ自動で割り当てる

- PNG 出力に加えて、元のマテリアルを複製した新しいマテリアル (`_AO.mat`) が作られ、メッシュのマテリアルがそれに自動で差し替わります。
- Unity 上で今すぐ陰影入りの見た目を確認したいときに便利です。

:::tip
アップロード（VRChat SDK の Build & Test）では、このトグルの状態にかかわらずマテリアルへ陰影が適用されます。
`テクスチャのみ` が切り替えるのは、手動ベイクの動作だけです。
:::

## 出力先

手動ベイクで作成されたファイルは以下の場所に保存されます。

```
Assets/EasyAOBakerOutput/<アバター名>_<日時>/
```

- フォルダ名には、処理対象のルート GameObject の名前が使われます。
- 日時フォルダが毎回作られるので、過去の結果は上書きされずに残ります。
- いらなくなったらフォルダごと削除して構いません。

## Play モードで確認する方法もあります

Play モード（`Ctrl+P`）に入ると、VRChat へのアップロード時と同じ処理が走り、陰影が適用されます。
Game ビューでは、アバター全体の見た目を確認できます。

- Play モード中に `EasyAOBaker` のパラメータをいじると、Edit モードに戻った後もその変更が保持されます。
- Play モードでは元のマテリアルが変更されないので、手軽にプレビューできます。

## うまくいかないときは

### ベイクしたマテリアル変更を元に戻したい

- `Ctrl+Z` で直前の変更を取り消せます。
- Inspector で Renderer のマテリアルスロットに元のマテリアルを再設定すれば戻せます。
- `Assets/EasyAOBakerOutput/` 以下のフォルダは、不要なら手動で削除してください。

### 結果が期待と違う

- [仕上がりの調整](./bake-modes.md) ページでパラメータの意味を確認してください。
- 目や口内など特定箇所だけ除外したい場合は、[マテリアル単位の ON/OFF](./material-selection.md) や [AO マスク](./ao-mask.md) を試してください。
