症状に対応する項目を上から確認し、原因を一つずつ切り分けてください。

## 全般

### Q. Scene ビューに制御点が表示されない

- Inspector の `ラティスエディターを開く` を押して `Mesh Deformer` ツールをアクティブにします。
- Scene ビューのツールバーで `Mesh Deformer` アイコンに切り替わっているか確認します。
- `Gizmos` トグルがオフになっていないか確認します。
- アクティブレイヤーがラティスレイヤー `[L]` になっているか確認します。
  ブラシレイヤー `[B]` では制御点が表示されません。

### Q. SkinnedMeshRenderer のポーズとラティスケージがずれる

- 1.4.2 以降へ更新し、ケージの各制御点が SkinnedMeshRenderer の現在のボーンポーズへ追従するか確認します。
- 表示位置だけを調整する場合は、Inspector の `Lattice Cage Alignment` にある `Offset` と `Scale` を使います。
  メッシュと最終的な変形結果には影響しません。
- 原因を調べる場合は、`(Debug) プレビューアラインをコンソールにログ出力` を一時的に有効化し、Console の位置合わせ情報を確認します。
  通常はオフにします。

### Q. プレビューを ON にしてもメッシュが更新されない

- Inspector の `メッシュ再構築オプション` を展開し、ボタンが `(NDMF) ラティスプレビューを無効化` と表示される状態でハンドルを操作しているか確認します。
- `変更後のグリッド分割数` を変更した場合は `適用` を押さないと制御点が再生成されません。
- Unity コンソールに NDMF 関連のエラーが出ている場合は、NDMF を 1.9.0 以降に更新してください。

### Q. 動作が重い

- ラティス分割数が高すぎる場合は、`変更後のグリッド分割数` を減らします。
  初期設定は `3, 3, 3` です。
- ブラシツールで `表面距離` を有効にしている場合、頂点数の多いメッシュでは計算に時間がかかることがあります。
  不要な場合はオフにしてください。
- `変位ヒートマップを表示` や `貫通表示` が有効な場合、Scene ビューの描画負荷が上がることがあります。

### Q. ビルドすると Mesh Deformer が消えてしまう

想定された動作です。
有効な `Mesh Deformer` は、変形結果をメッシュへベイクした後に自動で削除されます。

- NDMF の Build Pipeline でコンポーネントは自動削除され、代わりにベイク済みメッシュ (`*_MeshDeformed`) が割り当てられます。
- Play モードを抜けると削除されたコンポーネントは自動的に復活します。

### Q. パッケージを更新したら UI が英語に戻った

Inspector の `ツールの言語` ドロップダウンで `日本語` を選択し直してください。
設定は EditorPrefs に保存され、次回の Unity セッションにも引き継がれます。
保存値がない場合や値を読み込めない場合は英語になります。

### Q. 更新後に Scene または Prefab が変更済みになった

1.4.2 は旧 `BrushDeformer` を検出すると、変位と再構築設定を `LatticeDeformer` の専用グループとブラシレイヤーへ自動移行します。
対象は、編集可能なロード済み Scene、Prefab Stage、`Assets` 内のインポート済み Prefab です。

- 旧 `BrushDeformer` は削除されず、無効なバックアップとして残ります。
- Play Mode、コンパイル、インポート処理中は移行を待機します。
- 読み取り専用のアセットと Packages 内のアセットは変更しません。
- 移行に失敗した対象は元データを保持し、Console に警告を出します。
- 更新前の状態と比較して復元できるよう、パッケージ更新前にバージョン管理へコミットするか、バックアップしてください。

## ラティス編集

### Q. 対称編集がミラーされない

- オーバーレイの `対称編集を有効化` がオンになっているかチェックします。
- 設定した `対称軸` が正しいか確認します。
  色のついた面が、その軸に対応する対称面です。

### Q. 制御点をグローバル空間で移動できない

複数の制御点を選択している場合、グローバル空間での編集は無効になります。
制御点を一つだけ選択するか、ローカル空間で操作してください。

## ブラシツール

### Q. ブラシで塗っても変形しない

- アクティブレイヤーがブラシレイヤー `[B]` になっているか確認します。
- `ブラシ強度` が 0 に近い値になっていないか確認します。

### Q. ブラシがメッシュの裏側にも影響する

- `詳細設定` の `背面カリング` をオンにすると、カメラから見える面のみにブラシが適用されます。
- `表面距離` をオンにすると、メッシュ表面に沿った距離でブラシ範囲を計算するため、裏側への影響を防げます。

### Q. ブラシで別パーツのメッシュにまで影響する

`詳細設定` の `接続のみ` をオンにすると、ブラシ影響がメッシュのトポロジーで接続された頂点に限定されます。

## BlendShape

### Q. BlendShape 出力した変形が VRChat で動かない

- `BlendShape 名` が正しく設定されているか確認します。
- VRChat のアバターの Expression Parameters や Expression Menu で対応する BlendShape を制御しているか確認します。
- `テストモードに入る` で Unity 上で BlendShape が正しく動作するか事前に確認してください。

## ウェイト転送

### Q. ウェイト再計算後に関節の曲がりが不自然

- `最大転写距離` を大きくすると、より遠い元の頂点からもウェイトをコピーできるようになります。
- `法線角度閾値` を緩めると、より多くの頂点にウェイトが転写されます。
- Stage 2 の `補間を有効化` がオンになっていることを確認してください。

### Q. ウェイト再計算のオプションが表示されない

`ボーンウェイトを再計算` は `Skinned Mesh Renderer` を使用するメッシュでのみ利用可能です。
`Static Mesh Source` を使用している場合は表示されません。
